Асинхронний RESTful API для безстанційного шерингу електросамокатів. Побудований на сучасному стеку FastAPI та SQLAlchemy 2.0.

## :rocket: Стек технологій
- **FastAPI** - швидкий асинхронний вебфреймворк.
- **SQLAlchemy 2.0 (Asyncio)** - ORM для безпечної роботи з СУБД.
- **Pydantic v2 & Pydantic-Settings** - сувора валідація конфігурації та даних.
- **Uvicorn** - ASGI вебсервер.

---

## :tools: Як запустити проєкт локально

### 1. Клонування репозиторію
Завантажте проєкт з GitHub та перейдіть у його кореневу директорію:
```bash
git clone https://github.com/ADernRa/Scooter-API-FastAPI-SQLalchemy-
cd Scooter-API-FastAPI-SQLalchemy-
```

### 2. Налаштування віртуального оточення
Створіть та активуйте віртуальне оточення Python:
```bash
# Для Windows:
python -m venv venv
venv\Scripts\activate

# Для macOS/Linux:
python3 -m venv venv
source venv/bin/activate
```

### 3. Встановлення залежностей
Встановіть необхідні бібліотеки для роботи додатка:
```bash
pip install fastapi uvicorn pydantic-settings sqlalchemy aiosqlite
```

### 4. Налаштування змінних оточення
У кореневій папці проєкту створіть файл **`.env`** і додайте в нього такі налаштування (замініть значення на свої за потреби):
```text
DATABASE_URL=sqlite+aiosqlite:///./scooters.db
SECRET_KEY=your-super-discreet-jwt-key-here
ADMIN_TOKEN=super-secret-admin-token-123
DEBUG=True
```

### 5. Запуск сервера
Запустіть сервер розробки з автоматичним перезавантаженням при зміні коду:
```bash
uvicorn src.main:app --reload
```

Після запуску сервер буде доступний за адресою: `http://127.0.0.1:8000`

## :book: Документація API

Після запуску сервера інтерактивна документація Swagger UI з усіма схемами запитів та можливістю тестування ендпоінтів у реальному часі буде доступна за адресою:
:point_right: **`http://127.0.0`**

### Основні можливості (Ендпоінти):
- **Для користувачів (`/api/v1/user`)**: перегляд списку станцій, виведення доступних самокатів на конкретній точці, оренда самоката та завершення поїздки в будь-якій локації на вулиці з оновленням заряду батареї.
- **Для адміністрації (`/api/v1/admin`)**: захищені ендпоінти, що вимагають передачі секретного заголовка `X-Admin-Token`. Дозволяють створювати нові станції, видаляти елементи та проводити часткове оновлення будь-яких характеристик самокатів.
